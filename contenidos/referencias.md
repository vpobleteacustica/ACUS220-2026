# Referencias

Esta página reúne un conjunto **mínimo y fundamental** de recursos para acompañar ACUS220.

La intención no es construir una bibliografía exhaustiva. Utilizaremos estas referencias como puntos de entrada confiables hacia las herramientas y prácticas que iremos encontrando durante el curso.

## Documentación oficial fundamental

### Python

**Python Software Foundation.** *Python Documentation.*

<https://docs.python.org/3/>

La documentación oficial será nuestra referencia principal para el lenguaje Python, su biblioteca estándar y el uso del intérprete.

### Conda y entornos

**Conda Project.** *Conda Documentation.*

<https://docs.conda.io/>

Será nuestra referencia para creación y administración de entornos, instalación de paquetes y manejo de dependencias.

### Visual Studio Code

**Microsoft.** *Python in Visual Studio Code.*

<https://code.visualstudio.com/docs/languages/python>

La utilizaremos como referencia para selección de intérpretes, trabajo con entornos Python y herramientas de desarrollo dentro de VS Code.

### Jupyter

**Project Jupyter.** *Project Jupyter Documentation.*

<https://docs.jupyter.org/>

Será nuestra referencia principal para notebooks, kernels y el ecosistema Jupyter.

### Git

**Chacon, S. & Straub, B.** *Pro Git.*

<https://git-scm.com/book/en/v2>

Es una referencia abierta y fundamental para comprender Git, control de versiones y flujos de trabajo con repositorios.

### GitHub

**GitHub.** *GitHub Docs.*

<https://docs.github.com/>

La utilizaremos para repositorios remotos, colaboración y publicación de proyectos.

## Una idea para recordar

Las herramientas cambiarán con el tiempo.

Las versiones de Python, las librerías, los editores y las plataformas evolucionarán.

Por eso, además de aprender herramientas concretas, durante ACUS220 intentaremos desarrollar hábitos más permanentes:

- organizar un proyecto;
- documentar decisiones;
- registrar dependencias;
- controlar versiones;
- conservar datos originales;
- hacer trazable un análisis;
- comunicar lo realizado;
- facilitar que otra persona pueda comprender y reutilizar nuestro trabajo.
