## Bienvenida

**ACUS220 nace de una idea sencilla: aprender Python no termina cuando aprendemos su sintaxis.**

Python puede transformarse en una puerta de entrada hacia la computación científica, el análisis de datos, la visualización, el procesamiento de audio, el aprendizaje de máquina y el desarrollo de proyectos reproducibles.

En este curso utilizaremos problemas vinculados con la acústica para explorar ese ecosistema. El objetivo no será dominar todas sus herramientas, sino aprender a descubrirlas, utilizarlas críticamente y combinarlas para abordar problemas nuevos.

Queremos que Python deje de ser solamente *“el lenguaje que aprendí en un curso”* y comience a ser **un entorno de posibilidades**.

---

## ¿Qué entendemos por acústica computacional?

La acústica computacional no es solamente usar un computador para resolver ecuaciones acústicas.

También es aprender a trabajar con **datos, herramientas, modelos y flujos computacionales** que permiten abordar problemas acústicos en diálogo con otras disciplinas.

Durante el curso iremos descubriendo herramientas que hoy forman parte del trabajo científico y profesional en muchas áreas de la ingeniería:

- entornos de Python y gestión de librerías;
- Visual Studio Code y Jupyter;
- computación científica con Python;
- exploración, organización y visualización de datos;
- trabajo con señales y datos de audio;
- construcción y evaluación de modelos;
- primeros conceptos de aprendizaje de máquina;
- Git y GitHub;
- documentación y reproducibilidad;
- organización de proyectos computacionales.

No estudiaremos estas herramientas de manera aislada. Las utilizaremos para **hacer preguntas, explorar problemas y construir proyectos**.

## Python como un entorno de posibilidades

A lo largo del semestre veremos que aprender Python puede conducirnos progresivamente hacia un ecosistema mucho más amplio:

```text
Python
   ↓
computación científica
   ↓
datos
   ↓
visualización
   ↓
audio
   ↓
modelos
   ↓
aprendizaje de máquina
   ↓
Git y GitHub
   ↓
reproducibilidad
   ↓
trabajo interdisciplinario
```

## ¿Qué esperamos aprender?

Al finalizar el curso, frente a un problema nuevo, esperamos que puedas pensar algo parecido a esto:

> *Voy a crear un entorno, organizar mi proyecto, mirar los datos, entender qué representan, explorarlos, visualizarlos, buscar una librería adecuada, probar una metodología, evaluar lo que obtuve, documentarlo y dejarlo reproducible en un repositorio.*

El objetivo no es memorizar una colección de comandos ni obtener siempre el modelo con mejor desempeño.

El objetivo es desarrollar progresivamente **autonomía computacional**: aprender a explorar herramientas nuevas, tomar decisiones razonadas y construir un proceso de trabajo que otras personas puedan comprender y reproducir.

---

## Acústica en diálogo con otras disciplinas

Muchos problemas actuales difícilmente pertenecen a una sola disciplina.

Un proyecto acústico puede conducirnos hacia procesamiento de señales, ciencia de datos, informática, aprendizaje de máquina, bioacústica, medio ambiente, urbanismo, monitoreo, instrumentación o modelación.

Por eso, una parte importante de este curso será aprender también un **lenguaje computacional común** que nos permita colaborar con profesionales provenientes de otras áreas.

Python será nuestra herramienta de exploración.

Los problemas acústicos serán nuestro punto de partida.

Y el proyecto desarrollado durante el semestre será el espacio donde comenzaremos a conectar ambas cosas.
